# Windows 缓存清理工具

这是一个使用 Windows 自带 PowerShell 和 Windows Forms 的小工具，不需要安装第三方软件。

## 使用方法

双击 `启动缓存清理工具.bat`。程序会列出可扫描的缓存类别；点击“重新扫描”后查看各类别的文件数量和大小。点击列表中的类别可查看缓存用途与清理影响。勾选要处理的类别，再点击“清理已勾选项目…”并在确认框中确认，才会尝试删除文件。

工具默认不勾选项目。扫描不会修改文件。清理时只处理扫描清单中的文件，并跳过正在使用、无权访问、路径异常或重解析点（例如符号链接）。清理后会重新扫描；清理失败的文件不会强制处理。

## 可选类别

| 类别 | 文件用途 | 清理后的影响 |
| --- | --- | --- |
| 当前用户临时文件 | 应用安装、运行或更新时的暂存文件 | 通常会重新生成；正在使用的文件跳过 |
| Windows 临时文件 | Windows 和安装程序的临时工作文件 | 某些内容需要管理员权限或正被系统使用 |
| 缩略图与图标缓存 | 资源管理器保存的图片/视频预览和图标数据库 | Windows 会重建；首次浏览相关文件夹可能变慢 |
| DirectX 着色器缓存 | 图形应用和游戏保存的已编译着色器 | 可重新生成；游戏首次启动或进入场景可能短暂卡顿 |
| Windows 更新传递缓存 | 更新传递优化暂存、共享的更新内容 | Windows 可能重新下载内容，增加后续下载流量 |

建议先关闭正在运行的应用再清理。普通方式运行即可清理可访问的用户缓存；若也想处理 Windows 临时目录，可右键启动批处理并选择“以管理员身份运行”。无需管理员权限时，工具会跳过不可访问的项目。
